# pomo

把金额、商品或服务的价格，换算成赚取时间、储蓄时间与不同物品的购买数量，以客观、中性的方式帮助理解价值。

目前为漫画风格网页版，使用接近全屏的循环卡片交互，无需注册登录。Android App 在网页版验证后推进。

## 本地运行

需要 Node.js 22 或以上版本，无需安装运行依赖。

```sh
cd web
npm start
```

打开 <http://127.0.0.1:4317/>。可通过 `HOST`、`PORT` 环境变量调整监听地址和端口。

## 当前功能

- 输入金额，或联网查找商品、服务报价；服务支持补充城市。
- 报价展示来源、原文、抓取时间和类别，用户选择后进行比较；查价失败可手动填写。
- 每次显示 10 张卡片：赚、存固定，其余从 28 项比较池中随机搭配，覆盖数码、穿搭、娱乐、出行、运动及日用品。
- 金额达到 iPhone Duo 参考报价时，纳入可购买台数的比较。
- 右滑下一张、左滑上一张，循环切换且相邻卡片颜色不同。
- 全国统计参照、个人收支、本地历史、PNG 导出和离线缓存。

全国统计参照使用 2025 年数据，工资与居民收支采用不同统计口径。iPhone Duo 使用所列规格的官网公开报价，其他比较项为可调整预算参照，不是全国均价。网页报价、搜索摘要参考价不保证是当前可成交价格。详见 `web/数据口径.txt`。

## 搜索配置

默认使用公开搜索渠道，可选设置服务端环境变量 `TAVILY_API_KEY` 或 `BRAVE_SEARCH_API_KEY`。密钥应由运行环境提供，不放入前端或提交至仓库。公开搜索可能限流；缺少明确报价时显示来源并允许手动填写。

## 验证

```sh
cd web
npm test
```

浏览器检查需要 Playwright 和 Chrome，先启动服务，再执行：

```sh
npm run verify:web
node test/search-browser.cjs
node test/comparisons-browser.cjs
```

部分浏览器脚本包含原开发环境的运行时路径；其他环境需安装 Playwright 并调整脚本中的路径。更多说明见 `web/启动说明.txt` 和 `web/验收报告.txt`。

## 目录

- `web/`：当前网页版源码、服务端、构建脚本及测试。
- `prototype/`：早期交互原型。
- `ui/`：漫画 UI 设计与 SVG 素材。
- `需求记录.txt`、`pomo需求确认稿V1.0.txt`：需求与确认记录。

构建产物、浏览器测试缓存、截图导出和交付 ZIP 不纳入版本管理。
