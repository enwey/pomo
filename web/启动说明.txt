pomo 网页验证版 v0.1

环境：Node.js 22 或以上。运行本地网页不需要安装第三方依赖。

启动：
1. 在本文件所在的 web 文件夹打开终端。
2. 执行 npm start。
3. 浏览器打开 http://127.0.0.1:4317。

也可以分别执行：
node scripts/build.mjs
node server.mjs

默认仅本机访问。手机同局域网测试时，可在 PowerShell 设置：
$env:HOST = '0.0.0.0'
npm start
然后在手机访问“电脑局域网IP:4317”。手机与电脑需要处于同一网络，且系统允许该端口通信。离线缓存、系统分享等浏览器能力在HTTPS或本机localhost上更完整；局域网普通HTTP不等于这些能力的正式验收环境。

端口冲突时可设置：
$env:PORT = '4318'
npm start

代码：
src/：独立网页源文件，保留已确认的漫画UI。
public/：build生成的可服务静态文件及离线缓存脚本。
server.mjs：静态服务、统计数据及官网报价接口。
catalog.mjs：官网报价提取和型号匹配。
test/：计算、服务端和浏览器测试。

测试：
npm test
浏览器验证需预装Playwright和Chrome。本机已提供运行时；其他电脑可配置CHROME_PATH，并安装测试所需的Playwright。
先启动网页服务，再执行 npm run verify:web。
POMO_TEST_URL 可指定验证地址。

边界：
当前是本地网页验证版，不是互联网部署版本，也不是Android APK。
官网查价会从Apple在售iPhone目录发现型号，并覆盖iPad产品页；目录不可用时回退到内置型号清单。“iPhone 18”会展示明确标注的Pro／Pro Max候选，不冒充标准版。具体支持取决于官网是否仍公开完整SKU和价格；解析不到就返回手动填价，绝不生成虚假报价。其他商品／服务现已接入通用联网搜索，读取相关网页中的人民币报价。结果区分官网报价、网页参考价及搜索摘要参考价，并展示原文、来源和抓取时间。来源不保证包含当前可成交报价，需用户核对规格及条件。
每次显示10张卡片：赚、存固定，其他8张从28种比较项中随机抽取，覆盖数码、穿搭、娱乐、出行、运动及日用品。日用品最多2张（常规金额且候选充足时），优先买得起的物品。达到iPhone Duo报价时必含台数比较。iPhone Duo使用官网公开报价，其他物品为可调整预算参照，计算依据中标明。
空间装载比较及根据金额自动扩展卡片数量尚未实现，属于后续需求。
确认网页版体验及数据覆盖后，再推进Android实现。

通用查价（v0.2）
默认无需密钥，使用公开搜索渠道；搜索渠道可能限流或不可用。可在启动服务的进程环境中配置 TAVILY_API_KEY 或 BRAVE_SEARCH_API_KEY，优先使用相应搜索API。不要把密钥写进前端或提交到项目。
不需要为每个商品登记型号；Apple结构化官网采集作为补充优先来源。网页读取有超时、大小限制和内部网络地址防护，不绕过验证码。
通用搜索结果缓存60秒，Apple官网结果缓存5分钟；显示原抓取时间。抓取时间并非商家更新价格的时间。摘要价格可能较旧，网页参考价也可能有适用条件。
未提取到明确单价时展示找到的网页，允许手动填写；不把无报价说成商品不存在。
